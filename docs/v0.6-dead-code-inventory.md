## 大扫除分 5 阶段（每阶段一个 commit）

| 阶段 | 内容 | 风险 | 验证 |
|---|---|---|---|
| **S1** | 删 decision.rs 里 L1 计算逻辑（chase/rebal 死分支） | 低 | cargo check |
| **S2** | 删 signal.rs L1 死常量 + Thresholds 装填 | 中（要同步 decision Thresholds struct） | cargo check |
| **S3** | 简化 Thresholds struct（删 chase/rebal 字段） | 中（跨文件） | cargo check |
| **S4** | 删 L2 字段：rebalance_hint / chase_side | 高（5+ 文件级联） | cargo check + 跑一窗口验证 |
| **S5** | 清理空 use / 死辅助函数（weighted_avg 等） | 低 | cargo check |

**每个 stage 完成后 git commit 一次**，方便单独回滚某个阶段。

---

## 回滚预案

| 出问题 | 回滚命令 |
|---|---|
| 某 stage 编译失败 | `git reset --hard HEAD~1` |
| 引擎部署后跑不起来 | `git checkout main` + 重新部署 baseline |
| 想完全放弃清理 | `git checkout main` 即可 |
